Update about reservation calendar

10/29/2026

In response to increasing demand to use the LA-ICP-MS lab, I have created a scheduling page to use the laser. To keep things simple, I am just going to use a hard-coded HTML "reservation schedule" for now, but I will plan to set up a Google Calendar similar to the Petrology Lab in the future. Here's the URL:

Because of how the laser works, I want try making reservations by the half-day, where 10:00am is the start time for the morning "AM" time slot and 1:00pm is the start time for the afternoon "PM" time slot. This way, I (or the user) can start the system at 9:00am and be able to do analyses from 10:00pm until 1:00pm (3 hours). Then if the system is still on, the next user can do analyses from 1:00pm to 4:00pm (3 hours), allowing 30 minutes to an hour to shut everything down.

To make a reservation (or if you have any questions), please send me an email. Any day/time not marked as "reserved" is available.

-Lowell
