Update about reservation calendar

9/2/2026

Dear Petrology Lab users,

Because the number of Petrology Lab users has been steadily increasing, I have set up a scheduling calendar for whole rock sample prep activities in the lab.

The calendar can be found on this page: https://vtepma.github.io/pages/Petrology%20Lab.html (also via QR code posted on the inside of the lab door).

Similar to the microprobe calendar, please send me an email if you would like to reserve the room. Unlike the microprobe calendar, I think we can do the reservations for short durations instead of full days.

Please make a reservation if you are doing any of these activities:

  • Using the ball mill or shatter box
  • Doing anything involving acids or the fume hood (e.g. making beads in the fluxer)
  • Having an important meeting that you don't want to be disturbed by other activities.

You do not need to make a reservation for any of these activities:

  • Making coffee or tea
  • Using the microscope
  • Writing or studying
  • Polishing or using sieves (I am undecided about this one, but I think it's ok for now)
  • Having at meeting, but you don't care if others are working in the lab.

Please let me know if you have any questions.

Thanks,

Lowell
